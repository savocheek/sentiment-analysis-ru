# Тональность отзывов на русском (ruBERT)

Классификатор тональности русскоязычных отзывов: **негатив / нейтрально / позитив**.
Дообученный [`cointegrated/rubert-tiny2`](https://huggingface.co/cointegrated/rubert-tiny2) на отзывах с Яндекс Карт + веб-демо на Gradio.

![demo](reports/demo.png)

## Результаты

Тестовая выборка: 3 600 отзывов, классы сбалансированы.

| Модель | Macro-F1 | Accuracy |
|---|---|---|
| TF-IDF (1–2-граммы) + логистическая регрессия | 0.754 | — |
| **rubert-tiny2, fine-tune 3 эпохи** | **0.784** | **0.783** |

```
              precision    recall  f1-score   support
    negative     0.7707    0.7713    0.7710      1220
     neutral     0.6837    0.7123    0.6977      1199
    positive     0.9044    0.8654    0.8845      1181
```

<img src="reports/confusion_matrix.png" width="420">

**Что видно по ошибкам.** Модель почти не путает позитив с негативом (≈2%). Основные ошибки — на границе с «нейтрально»: отзыв на 3★ обычно смешанный («номер чистый, но шумно»), а автор отзыва на 2★ или 4★ часто пишет так же. Это шум в самой разметке «по звёздам», а не только слабость модели.

## Стресс-тест в искусственных условиях

`python stress_test.py` → полный отчёт в [reports/stress_test.md](reports/stress_test.md).

**25 сложных отзывов, написанных вручную: 17/25.**

| Справляется | Не справляется |
|---|---|
| смешанные отзывы 3/3, сленг и эмодзи 3/3, опечатки 2/2, отзывы о товарах и фильмах (другой домен) 3/3, короткие «Отлично!» / «Ужас.» 3/3 | **сарказм 0/3** («Спасибо огромное за холодную пиццу и хамство» → позитив), **двойное отрицание 1/4** («Ни разу не пожалели» → негатив), «ЛУЧШЕЕ МЕСТО!!!» капсом → негатив |

**Устойчивость к шуму** (600 реальных отзывов, accuracy 0.770 без искажений):

| Искажение | Accuracy | Ответ изменился |
|---|---|---|
| нижний регистр | 0.757 | 5.8% |
| без пунктуации | 0.762 | 7.2% |
| −30% слов | 0.740 | 13.3% |
| только первые 10 слов | 0.650 | 26.3% |
| опечатки в 10% букв | 0.610 | 26.0% |

**Граничные входы** (эмодзи, `5/5`, HTML, одна буква, 3 200 символов) — ничего не падает. На пустых по смыслу входах модель честно не уверена (≈0.4–0.5), но HTML-мусор `<div>&nbsp;</div>` уверенно (0.73) считает негативом — перед моделью стоит чистить разметку.

**Скорость:** 3.3 мс на отзыв, ~380 отзывов/с пачкой (Apple M3, MPS).

**Вывод:** модель опирается на окрашенные слова («супер», «спасибо», «не»), а не на смысл фразы целиком — отсюда провал на сарказме и отрицаниях. Это типично для маленькой модели, обученной на звёздах; лечится моделью покрупнее и добавлением таких примеров в обучение.

## Данные

[`d0rj/geo-reviews-dataset-2023`](https://huggingface.co/datasets/d0rj/geo-reviews-dataset-2023) — 500 000 отзывов об организациях с Яндекс Карт (MIT).

- Разметка по рейтингу: 1–2★ → негатив, 3★ → нейтрально, 4–5★ → позитив.
- Исходно 86% отзывов позитивные, поэтому взято по 12 000 на класс (36 000 всего).
- Разбиение 80 / 10 / 10 (train / val / test), `seed=42`.

## Обучение

- `max_length=256`, batch 32, lr 5e-5, warmup 6%, weight decay 0.01, 3 эпохи.
- Лучший чекпоинт выбирается по macro-F1 на валидации.
- ~13 минут на Apple M3 (MPS), модель 29M параметров, 114 МБ.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python train.py          # скачает датасет, обучит бейзлайн и модель → ./model, ./reports
python app.py            # веб-демо на http://127.0.0.1:7860
pytest -q                # смоук-тесты модели
```

Флаги `train.py`: `--per-class` (сколько отзывов на класс), `--epochs`, `--out`.
`app.py` читает модель из `MODEL_PATH` (локальная папка или id на Hugging Face Hub).

## Структура

```
train.py        данные → бейзлайн → fine-tune → метрики и графики
app.py          Gradio-интерфейс
test_app.py     тесты
stress_test.py  стресс-тест: сарказм, отрицания, шум, граничные входы, скорость
reports/        метрики, отчёт, матрица ошибок, скриншот
```

## Что можно улучшить

- Взять `ai-forever/ruBert-base` вместо tiny-версии (медленнее в ~10 раз, ожидаемо +2–4 п. F1).
- Разметить «нейтрально» вручную вместо звёзд — главный источник ошибок.
- Выложить веса на Hugging Face Hub и демо на HF Spaces.
